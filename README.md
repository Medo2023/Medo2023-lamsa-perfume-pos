# لمسة عطر — نظام إدارة ونقاط بيع العطور

تطبيق ويب عربي لإدارة المتجر والمبيعات والمخزون، مع مزامنة Firebase وإمكانية تثبيته كتطبيق على الهاتف أو الحاسوب.

## رابط الموقع

[فتح لمسة عطر](https://medo2023.github.io/Medo2023-lamsa-perfume-pos/)

## تسجيل الدخول

- الدخول بحساب Google المصرح به فقط؛ لا توجد رموز PIN محلية.
- حساب المالك مُعد مسبقًا. لإضافة طارق، سجّل كمالك وافتح **إدارة الموظفين** ثم أضف اسمه وبريد Google والدور والصلاحيات المناسبة. على طارق الدخول بالبريد نفسه.
- قواعد Firestore تتحقق من هوية Google وسجل الحساب النشط، وتقيّد المجموعات الحساسة بحسب الصلاحية. في بنية المبيعات والمنتجات الحالية تبقى حقول التكلفة والربح قابلة للقراءة لمستخدم يمكنه قراءة هذه السجلات.

## تثبيت التطبيق على الأجهزة

افتح الرابط في Safari على iPhone/iPad واستخدم **إضافة إلى الشاشة الرئيسية**، أو في Chrome/Edge اختر **تثبيت التطبيق**. يعمل الموقع على الهواتف وأجهزة الحاسوب.

## العمل دون اتصال والمزامنة بين الأجهزة

سجّل الدخول وحمّل بيانات المتجر مرة واحدة مع الإنترنت. بعدها يحتفظ التطبيق بملفاته وبيانات Firestore التي سبق تحميلها على الجهاز، ويمكنه العمل دون اتصال. تُحفظ التغييرات محلياً وتُزامن تلقائياً عند عودة الإنترنت؛ أما الأجهزة المتصلة والمصرح لها فتتلقى تغييرات Firestore في الوقت الفعلي. لا تسجّل الخروج قبل مزامنة التعديلات المعلقة. أول تسجيل دخول يحتاج إلى الإنترنت، ويستخدم Google نافذة منفصلة على GitHub Pages؛ افتح الرابط في Chrome أو Safari مباشرة واسمح بالنوافذ المنبثقة إذا منعها المتصفح.

## تطوير محلي

يتطلب Node.js 22 أو أحدث.

```bash
npm ci
npm run dev
```

لفحص TypeScript وبناء نسخة الإنتاج:

```bash
npm run lint
npm run build
```

## النشر والتكلفة

المستودع عام لأن GitHub Pages متاح مجانًا هنا للمستودعات العامة. كل تحديث إلى `main` يشغّل GitHub Actions لبناء الموقع ونشره تلقائيًا. الاستضافة على GitHub Pages مجانية؛ قاعدة Firestore الحالية من فئة Enterprise وقد تترتب عليها رسوم استخدام مستقلة.

ملف `firebase-applet-config.json` يحتوي إعدادات عميل Firebase اللازمة للويب، وهي معرّفات عامة وليست مفاتيح خادم. حماية بيانات المتجر تعتمد على قواعد `firestore.rules`. لا تضف مفاتيح Gemini أو بيانات اعتماد خادم إلى المستودع.
